Comparer deux versions du design

Choisissez deux versions et un écran. Le curseur découvre la version B (à gauche) par-dessus la version A (à droite). Servez le dossier docs/design avec python -m http.server 8099 puis ouvrez http://127.0.0.1:8099/outils/compare.html (un fichier local ne peut pas lire l'index).
