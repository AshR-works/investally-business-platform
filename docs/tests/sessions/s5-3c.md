## Avant de commencer
- Pile locale prête (`node scripts/local-stack.mjs --seed=demo --rebuild`) ; comptes de démonstration (mots de passe dans le fichier local, jamais dans le dépôt).
- Rôles utiles : Responsable Investudy, Super administrateur, Direction, Responsable commercial, un chargé de compte, un formateur.
- Préparer une session **clôturée** avec au moins un inscrit confirmé évalué (présence et note), dont un apprenant d'une entreprise.

## Vérifications à rejouer
| N° | Vérification | Résultat attendu (d'après la recette) | Constaté (✔ / ✘) | Date et initiales |
|---|---|---|---|---|
| 1 | Délivrance seulement une fois clôturée | Toute tentative sur une session ouverte est refusée (422) | ☐ | |
| 2 | Seuils respectés selon le type | Certificat : présence et note atteintes ; attestation : présence seule suffit ; sinon refusé (422, voir la feuille d'évaluation) | ☐ | |
| 3 | Qui délivre, qui révoque, qui lit | Délivrance et révocation : Responsable Investudy et Super administrateur seulement ; lecture : les deux, la Direction (lecture seule) et le formateur lié à sa propre session ; un chargé de compte ne voit rien | ☐ | |
